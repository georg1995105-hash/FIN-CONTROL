# FIN CONTROL — alpha04: учебные счета и локальная история

**Задача:** дать владельцу возможность самостоятельно опробовать существующий финансовый сценарий даже без своих чеков. Не добавлять ещё один симулятор расчёта или фиктивную демонстрацию: картинки с реальными пикселями рендерятся на устройстве и обрабатываются штатным офлайн-Tesseract; источник и скрин явно помечены «УЧЕБНЫЙ ПРИМЕР».

## Реализовано

- Два программно нарисованных на устройстве вымышленных одностраничных русскоязычных счёта: один без расхождений, второй с ошибочной напечатанной суммой. Стандартный путь: bitmap → Tesseract → наблюдаемые строки → пользователь подтверждает итог, все строки и полноту → BigDecimal → понятные разницы.
- Сохранение результатов только после отдельного явного нажатия «Сохранить проверку», и только после полного подтверждения исходных данных. При сохранении проверка повторно запускается из исходных строк, а не доверяет UI-флагу. База SQLite внутри приложения: дата, заголовок, статус, исходные строки/числа, расчёт, демо-маркер. **Исходные изображения не сохраняются**.
- Экран «История» показывает локально сохранённые результаты, детали, экспорт в выбранный пользователем TXT через стандартный системный диалог, удаление только с подтверждением. Никаких сетевых разрешений и платных SDK; сохранение/чтение в фоновой IO-диспетчеризации.
- Версия 0.1.0-alpha04 / code 4. Все прежние финансовые тесты остаются обязательными; добавлены проверки строгой маркировки и полного подтверждения учебных документов.

## Измеренные и неизмеренные критерии

Ранее на CI 45901047513: Android alpha03 собирался, lint проходил, финансовые Kotlin-тесты 135/135. На CI 45901250521: 10/10 *синтетических* PNG с Linux Tesseract и 5 корректными отказами. **Ни одно из этих измерений не доказывает запуск новой alpha04 на Android, работу локальной БД, качество на реальных счетах или стабильность камеры.** Порог QUALITY_GATE.md не меняется.

Демонстрационные изображения — не пользовательские документы и не замена независимому корпусу. Результаты реальных чеков/смет по-прежнему могут быть отклонены строгим парсером; нельзя называть недоказанную переплату установленной. История хранится локально и переживает штатное обновление **при той же подписи APK**; при удалении приложения (неизбежном при старых несовместимых debug-подписях) она будет потеряна. До выпуска нужен постоянный защищённый ключ, предусмотренный в отдельном PR, проверенная установка поверх и резервное копирование/восстановление.
