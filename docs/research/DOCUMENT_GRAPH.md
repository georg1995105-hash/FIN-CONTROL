# Document semantic graph

After run 45870200103, whole-page Tesseract and native TSV both provided 0/89 cross candidates. Repeating segmentation without evidence is not justified. CDEK receipt-ocr-ru supplies machine-generated boxes (https://huggingface.co/datasets/cdek-ocr/receipt-ocr-ru); localization is not independently verified.

Experiment: build a graph of OCR rows, amount-bearing rows, aligned columns, neighboring semantic roles (item, payment, tax, discount, fiscal footer), distances and relative heights. Train compact logistic and MLP rankers on the same 160 real train documents and 240 structured synthetic examples as baseline. Compare on identical Paddle observations, unchanged exact explicit-label and rank/ocr/margin gates. No amount magnitude, arithmetic inference, reference values or annotations in features; amount identity repeats already in baseline. Report top1/rank-only as diagnostics only; never automatic financial approval. Reference coverage, repeated locations, unresolved labels, explicit links, nonfinal roles and conflicts are measured separately on held-out data. Identical 89 reused real and 40 synthetic image cases; additional 120 structured negative/positive tests, not independent images. No raw text, images, identifiers or weights stored.

This is a research branch, not Android deployment; manual reference, device latency, and full line-item extraction remain open. No new dependency or paid API, no design changes. The model may still have no improvement because explicit labels are missing; in that case use measured diagnostic breakdown to decide next recognition/semantic architecture.
