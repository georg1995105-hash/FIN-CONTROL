# FIN CONTROL — постоянная подпись и обновления без удаления

## Фактически установленная причина

Выполнена независимая проверка APK Signature Scheme v2 на двух ранее опубликованных файлах:

- alpha01 из Actions 45890986424: SHA-256 сертификата `c4b443d41185bdc5ce6354912dcef38fe7ba7136ff021d314e2805f4dafafd6a`.
- alpha02 из Actions 45896019617: SHA-256 сертификата `9c398298c3a5acd296705fb4eea7839e56084a3278b791d3ce5801d4a33c5af4`.

Пакет совпадает: `pro.veor.fincontrol`; код версии alpha02 равен 2. Сертификаты разные, поэтому установка поверх alpha01 невозможна. Исходный приватный debug-ключ из временного GitHub Runner не сохранялся; сертификат из APK не позволяет его восстановить. В текущей alpha01 история не реализована, только тема в SharedPreferences и снимки в кэше.

## Исправление для будущих версий

В этой ветке предусмотрены:
- локальный генератор постоянного приватного ключа `tools/android/init_keystore.sh`, без сохранения в репозитории;
- ручной GitHub Actions workflow `.github/workflows/android-stable-signing.yml`; он требует секреты и **отказывается** собирать подписанную версию без них;
- проверка пары APK `tools/android/verify_upgrade_pair.sh`, блокирующая смену пакета, сертификата или понижение/повтор версии.

Требуются GitHub Actions secrets: `FC_RELEASE_KEYSTORE_B64` (base64 PKCS12), `FC_RELEASE_STORE_PASSWORD`, `FC_RELEASE_KEY_ALIAS`, `FC_RELEASE_KEY_PASSWORD`, `FC_RELEASE_CERT_SHA256` (64 hex SHA-256 сертификата). Хранить ключ и резервную копию только в защищённом хранилище, не в Git, чатах и публичных артефактах.

Подпись не осуществлена: соответствующие secrets пока не настроены, управлять ими через имеющийся GitHub connector нельзя. Workflow доступен для воспроизводимой проверки после подключения ключа. Первая версия с постоянной подписью также **не обновит** старый debug APK; однако последующие версии с тем же постоянным ключом и новым versionCode смогут устанавливаться поверх.

Официального OTA, проверки реальной установки на телефоне, надёжной истории и коммерческого допуска пока нет. Девять утверждённых экранов и порог качества не изменяются.
